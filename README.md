# ross_ros_web

The website of **rOS**, my flavor of Arch Linux: <https://ros.rossmel.com>.

Plain HTML and CSS in `site/`, published to GitHub Pages by `.github/workflows/deploy.yml`.
The programs and the package repositories live at <https://repo.rossmel.com>
([ross_packages](https://github.com/rossmelabasto/ross_packages)).

Until everyone who added the old address has switched, the deploy also serves a copy of the
program repositories at their former paths here (`/arch`, `/apt`, `/rpm`, `/key.asc`,
`/check.sh`).
